Core Design Assumption: FCSA is engineered to investigate suspects when you do NOT have their physical phone in custody. All tracking, location estimation, and network profiling are calculated using network-side carrier Call Detail Records (CDR) alone.

1. System User Roles & Separation of Duties

FCSA segregates system administration from active investigations to maintain audit compliance and casework integrity.

User Role Primary Responsibilities
Admin (System Administrator) • Carrier Normalizer: Configures operator templates so Jio, Airtel, Vi, and BSNL CDR formats map automatically.
• AI Engine Trainer: Calibrates and trains the ML coordinate prediction weights for suspect location forecasting.
• Security Auditor: Inspects system-wide tamper-proof access logs to audit analyst casework.
Analyst (Cyber Cell Investigator) • Log Ingester: Uploads cell tower logs (CDR) into cases.
• Spatiotemporal Analyzer: Traces target tower-hopping trails, active hours, and hotspots on interactive maps.
• OSINT Investigator: Runs automated queries for WhatsApp, Signal, and historical threat databases.
• Case Exporter: Drafts legal orders and generates unified case dossier summaries.

3. Analyst Dashboard Workspaces & Features

The Analyst Panel is divided into dedicated workspaces, mapping every phase of a telecommunications investigation:

  • Upload Center: The entry point for case evidence. Investigators upload raw carrier CSV files here. The system standardizes columns, checks file integrity, and passes data to the normalization mapper.
  • Dashboard: Displays an executive overview of the case. It contains target threat classification labels (e.g. Highly Suspect Mule vs. Normal User), risk meters, and charts summarizing call vs. SMS volume.
  • Chrono Replay: Features an interactive Leaflet map that replays the suspect's movements chronologically. Investigators can control playback speed to track geographic tower hops over time.
  • Risk Center: Focuses on indicators of compromise. It lists the raw behavioral rules, flags critical alarms (e.g. multi-bank mappings), and scores target threat indexes.
  • Mobility Tracker: Analyzes spatiotemporal habits. It separates cell connections by hours to identify residential tower areas (active overnight) vs. daylight hiding spots.
  • Geo Intelligence: Displays spatial heatmaps and lists target roaming networks. It highlights and flags known high-risk cyber circles.
  • Network Analysis: Builds a dynamic 2D link node diagram connecting target numbers, contacted parties, active cell towers, recipient bank codes, and handset IMEIs to expose criminal groups.
  • Active Cases: Lists all ongoing cell investigations, letting analysts switch cases and edit target dossiers.
  • OSINT & Automation: Displays live API results, threat feeds matching target records, and status reports for external alerts.

4. Detailed Explanation of Cyber Features

FCSA automates 7 core cyber forensics features directly from the suspect's phone number, searching external public data networks and local platforms:

  • 1. OSINT (Open Source Intelligence): Queries multiple public directory databases using the target's phone number to harvest digital footprints and identify links to external web profiles.
  • 2. Wassenger (WhatsApp Integration): Queries the Wassenger API to check if the suspect number is registered on WhatsApp. It identifies whether the profile is Personal or Business, maps their unique WhatsApp ID (WID), and checks status timestamps.
  • 3. Signal (Encrypted Messenger Check): Queries Signal Messenger registries to see if the suspect line has been registered for encrypted messaging, which is common among advanced threat actors to hide communications.
  • 4. Carrier Info (Operator Verification): Retrieves real-time, official details about the telecom provider (Jio, Airtel, Vi) and geographic circle/region from international registry systems, verifying the true operator footprint of the target.
  • 5. MISP (Malware Information Sharing Platform): Connects directly to the local MISP repository. It cross-references the suspect's number against historical databases of blacklisted phone numbers used in phishing, financial extortion, and online scams. If a match is found, FCSA flags a Critical Threat alarm.
  • 6. Splunk (SIEM Log Analytics): Integrates with Splunk by piping investigation events, case updates, and threat metrics directly into SIEM indexes for permanent, compliant audit logging.
  • 7. Slack (Real-time Alerts): Uses automated webhooks to instantly push notifications to the Cyber Cell’s active operations channel on Slack whenever a suspect with a high-threat score is identified.

5. Detailed Explanation of AI Features

To track organized crime cells efficiently, FCSA integrates advanced machine learning models and heuristic indicators:

  • Cell Tower (CGI) Trajectory Estimation: Extracts the operator's tower identifiers (First CGI) and physical coordinates (First CGI Lat/Long) from the CDR. By chaining these coordinates chronologically, the system reconstructs the suspect’s exact movement path, showing which towers they hopped between over time.
  • ML Location Forecasting: An AI predictor (trained on historical tower-hopping sequences in the Admin Dashboard) calculates the suspect's location drift and projects their next estimated coordinate grid sector, allowing proactive search grid positioning.
  • Impossible Velocity Warnings (SIM Cloning): Calculates the travel speed between consecutive tower connections. If a suspect's SIM registers in Tower A (Delhi) and then Tower B (Mumbai) within a timeframe indicating a speed of >1000 km/h, FCSA flags a SIM Cloning Alert (proving SIM box operations or cloned card activity).
  • Money Mule Heuristics: Automatically flags money-laundering cards. It alerts when a prepaid SIM acts as an alert aggregator receiving SMS alerts from 5 or more distinct financial entities (SBI, HDFC, etc.) or shows high-frequency bursts of outgoing SMS to UPI registration codes (like GPAY/PhonePe activation gateways).
  • Spatiotemporal Hotspot Clustering: Groups connections by timestamp to separate the suspect's habits. Tower hops registered overnight (10:00 PM to 6:00 AM) are clustered to identify the suspect's Residential Footprint, while daytime hops map their **Operational Hideouts**.

6. Legal Request & Report Generator

FCSA speeds up legal paperwork and case reporting by automating document exports:

  • Section 91 CrPC Notice Drafts: Instantly generates formal police letters based on the suspect's activity:
    • Freeze bank accounts linked to the suspect's money-mule activity.
    • Block the phone hardware (IMEIs) across all national networks using the CEIR registry.
    • Request UPI logs from the National Payments Corporation of India (NPCI) to trace money transfers.
  • One-Click PDF Dossier Exporter: Compiles all maps, timeline routes, threat indicators, audit logs, and legal notices into a courtroom-ready PDF document to present to senior officers or the judge.
