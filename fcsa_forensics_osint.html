Cyber Forensics Feature Suite

FCSA automates 7 key cyber forensics features directly from the suspect's phone number. By querying external databases and security registries, the system builds a complete digital profile of the target without needing physical access to the device.

The 7 Core Cyber Features

1. OSINT (Open Source Intelligence)

Queries multiple public directory databases using the target's phone number to harvest digital footprints and identify links to external web profiles.

2. Wassenger (WhatsApp Integration)

Queries the Wassenger API to check if the suspect number is registered on WhatsApp. It identifies whether the profile is Personal or Business, maps their unique WhatsApp ID (WID), and checks status timestamps.

3. Signal (Encrypted Messenger Check)

Queries Signal Messenger registries to see if the suspect line has been registered for encrypted messaging, which is common among advanced threat actors to hide communications.

4. Carrier Info (Operator Verification)

Retrieves real-time, official details about the telecom provider (Jio, Airtel, Vi) and geographic circle/region from international registry systems, verifying the true operator footprint of the target.

5. MISP (Malware Information Sharing Platform)

Connects directly to the local MISP repository. It cross-references the suspect's number against historical databases of blacklisted phone numbers used in phishing, financial extortion, and online scams. If a match is found, FCSA flags a Critical Threat alarm.

6. Splunk (SIEM Log Analytics)

Integrates with Splunk by piping investigation events, case updates, and threat metrics directly into SIEM indexes for permanent, compliant audit logging.

7. Slack (Real-time Alerts)

Uses automated webhooks to instantly push notifications to the Cyber Cell’s active operations channel on Slack whenever a suspect with a high-threat score is identified.
